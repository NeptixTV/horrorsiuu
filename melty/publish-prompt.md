# Zusatz zum Melty-Publish-Prompt

So gehst du vor:

1. In Melty auf der *Create*-Seite (Hello Neighbor + Minecraft: Java Edition ausgewählt)
   den **Publish-Prompt** kopieren. Er enthält deinen Zugangs-Token.
2. Claude Code auf deinem PC im Ordner dieses Repos öffnen und den Prompt einfügen.
3. Unter die letzte Zeile des Prompts („If anything is written below this line …“) den
   folgenden Text einfügen und absenden.

Den Token nie in dieses Repo kopieren.

---

```text
Das Projekt ist das GitHub-Repo NeptixTV/horrorsiuu (dieser Ordner). Lies zuerst melty/README.md.
Minecraft: Java Edition ist der Host (primary), Hello Neighbor ist companion und wird aus dem
installierten Spielordner des Spielers gelesen. Kein Browser- oder Unreal-Web-Build: es wird
eine echte Minecraft-Mod, ausgeliefert als portable Prism-Launcher-Instanz mit Loader.
Nutze das Konzept und Grundgerüst aus dem Repo, sofern vorhanden.
Suche selbst passende Features, Musik und Klick-Sounds, solange ihre Lizenz die Weitergabe
erlaubt, und nenne die Urheber in den Credits.
Antworte mir auf Deutsch.
Lass das Listing als Entwurf und frag mich vor publish.
```
